# Bibliotecatronx-3000

Sistema de gerenciamento de biblioteca desenvolvido em C para a disciplina de **Estrutura de Dados I**.

## Como compilar e executar

### 1. Compilação

Na raiz do projeto, execute o seguinte comando no terminal:

```bash
gcc -Wall src/main.c src/menu.c src/livro.c src/usuario.c -o biblioteca
```
